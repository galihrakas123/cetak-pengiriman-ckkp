# Dashboard Pengiriman SKKP

Base starter template & monitoring dashboard untuk Pengiriman SKKP (Surat Ketetapan Kewajiban Pembayaran).

## 🚀 Fitur & Struktur
- **Modern UI / UX**: Tailwind CSS + Shadcn UI + Framer Motion.
- **Routing & Guards**: React Router v6 dengan lazy-loading dan route guards (`AuthGuard`, `GuestGuard`).
- **Reusable Component Library**: Tombol, Input, Modal/Dialog, Toast, Calendar/Date Picker, Base Tables with Pagination & Sorting.
- **Dynamic Layout & Sidebar**: Sidebar responsif collapsible yang dikonfigurasi melalui `src/utils/menuItems.ts`.

## 🛠️ Menjalankan Proyek

```bash
# Install dependencies
npm install

# Menjalankan development server
npm run dev

# Build untuk produksi
npm run build
```
